# Activity: My Portfolio
Create a React based Portfolio that shows details about you.

> Display all routes in a header navigation.

# Pages
- About me (Landing page)
    - Picture
    - Full name
    - Motto/ Tag line
    - Description about you
    - At least 3 contacts
- Hobby
    > Apply dynamic route, for example

    > localhost:5173/hobby/1

    > localhost:5173/hobby/2

    > localhost:5173/hobby/3
    - Picture
    - Name
    - Description about the hobby
    - Your reason for liking that activity/hobby

## Clue
1. Layout the Hobby page.
2. Create a collection of objects that has the details stated above (in Hobby page)
3. Display the contents of the hobby page as dynamic or in conditional rendering.
